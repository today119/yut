# 🎲 윷놀이

두 팀이 겨루는 윷놀이 판. **폰을 TV에 미러링해** 온 가족이 함께 보도록 만들었다.

👉 **https://today119.github.io/yut/**

## 쓰는 법
1. 팀 이름·**말 개수(팀마다 1~4개)**·색을 정한다
2. 실제 윷을 던지고 **나온 결과 버튼**을 누른다 (설정에서 「앱이 대신 던지기」로 바꿀 수 있다)
3. 판에서 **흰 점선으로 깜빡이는 자리**가 갈 수 있는 곳 — 옮길 말을 누른다
4. 대기 말이 있으면 **「새 말 출발」** 이 같이 뜬다
5. 말이 전부 나면 승리

## 규칙
- **지름길**은 꼭짓점(모·뒷모)에 **정확히 멈췄을 때만** 탄다
- **중앙(방)에 정확히 서면** 도착 쪽 지름길로 빠진다 — 최단 11칸
- 중앙을 **지나치면** 원래 대각선을 그대로 탄다
- **윷·모**가 나오면 한 번 더, 상대 말을 **잡아도** 한 번 더
- 같은 칸에 선 우리 말은 **업혀서** 함께 움직인다 (말에 개수가 찍힌다)
- **백도**는 기본으로 켜져 있다. 첫 칸에서 백도면 출발점으로 간다
- 도착은 **딱 안 맞아도** 난다

던진 결과는 **쌓인다**. 모→윷→개가 나오면 칩 3개가 뜨고, 어느 결과를 어느 말에 쓸지 골라서 옮긴다.

## 만든 방식
파일 하나(`index.html`)뿐이고 빌드도 서버도 없다. 크기는 전부 `vmin` 이라 폰 세로든 TV 가로든 화면에 맞춰 같이 커진다.

판·경로 규칙은 화면과 분리해 **node 테스트 40개**로 먼저 검증했다 — 윷판 경로가 제일 틀리기 쉬운 곳이라서.
